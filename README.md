# Movies API

Учебный проект API для работы с каталогом фильмов.

## Описание проекта
Приложение позволяет добавлять, просматривать, изменять и удалять фильмы.

## Основные возможности
- Добавление, просмотр, изменение и удаление фильмов.
- Фильтрация и сортировка списка.
- Проверка данных.
- Работа с базой данных и миграциями.
- Тестирование приложения.

## Технологии
- **FastAPI** — создание API.
- **Pydantic** — проверка данных.
- **SQLAlchemy** — работа с базой данных.
- **SQLite** — база данных.
- **aiosqlite** — асинхронное подключение к SQLite.
- **Alembic** — миграции базы данных.
- **pytest** — тесты.

## Быстрый старт

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/bxzlk/prod.git
   cd movies_api
   ```

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Примените миграции:

   ```bash
   alembic upgrade head
   ```

4. Запустите приложение:

   ```bash
   uvicorn src.main:app --reload
   ```

## Основные эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | Проверить работу API |
| GET | `/movies/` | Получить список фильмов |
| GET | `/movies/{id}` | Получить фильм по ID |
| POST | `/movies/` | Добавить фильм |
| PUT | `/movies/{id}` | Полностью изменить фильм |
| PATCH | `/movies/{id}` | Частично изменить фильм |
| DELETE | `/movies/{id}` | Удалить фильм |

## Фильтрация и сортировка

Для списка фильмов доступны параметры:

- `year_min` — год выпуска от.
- `year_max` — год выпуска до.
- `min_rating` — минимальный рейтинг.
- `order_by` — сортировка по `title`, `year` или `rating`. Знак `-` перед полем задаёт обратный порядок.
- `limit` — количество фильмов (максимум 100).
- `offset` — смещение списка.

Пример:

```http
GET /movies/?year_min=2000&min_rating=7.0&order_by=-rating&limit=10
```

## Модель данных

У фильма есть поля:

- `id` — уникальный номер.
- `title` — название (2–200 символов).
- `genre` — жанр (2–100 символов).
- `rating` — рейтинг от 0 до 10.
- `year` — год выпуска (не раньше 1888 года и не позже текущего года).

## Ограничения базы данных

- Рейтинг должен быть от 0 до 10.
- Год выпуска должен быть не раньше 1888 года.
- Название и жанр не должны быть пустыми.
